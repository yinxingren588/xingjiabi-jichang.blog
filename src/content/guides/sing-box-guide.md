## ⚡ 什么是 Sing-box？

Sing-box 是新一代的通用网络代理通用核心（Universal Proxy Platform），以**高吞吐、超低 CPU 和内存消耗、原生全协议栈**闻名。很多追求极致性能和新型协议（如 VLESS-Reality、Hysteria2、TUIC）的极客玩家正在全面转向 Sing-box。

---

## 📱 平台下载渠道

- **Windows / macOS**：图形化界面客户端可在 GitHub 仓库发布页下载。
- **Android**：可在 Google Play 商店或 GitHub Release 下载官方 APK。
- **iOS**：美区 App Store 搜索 `Sing-box` 即可免费下载安装。

---

## 📥 订阅导入三步曲

1. 从机场后台获取 **Sing-box 订阅链接**（如果机场暂未提供原生 Sing-box 格式，可使用在线转换工具或机场提供的通用聚合链接）。
2. 打开 Sing-box App，点击 **Profiles (配置)** -> 点击右上角 **+ (添加)**。
3. 选择 **Remote Profile (远程配置)**，输入机场名称，粘贴订阅 URL，点击 **Save (保存)**。
4. 返回首页点击 **Start (启动)**，即可开启加速通道。
